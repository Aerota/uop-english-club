# Peradeniya English Hub

I want to make a website with the above page vibe, means. Using the theme of the above page, with a blue colour like in "https://eng.pdn.ac.lk/". This website is for the "5-10 Group AB ", the English language program team in the Faculty of Engineering, University of Peradeniya. We are going to put our work on English programs on this site. We want to upload our assignments, group activities, presentations, etc to this site. There is one page where people can select which group activities and which group they want to know. If they select one, they can see the members of that group, details and a description of the group. Because of a large amount of data(pdf, videos, presentations), we have to link to a large database. Find a free, suitable, affordable large database storage service for the site and link it. The functions that are on the website are below. 
Same home page content for a professional website.
About page to showcase the teachers' panel of English and web committee and other committees that will be announced later.
There are 6 login accounts. 5 group logins and 1 admin login. Don't show the login page on the public site. Just give us the link for it. For security reasons, we don't have to publish the login page to everyone. 
Give admin all editing(edit, delete, reupload) options on content,  and logins to edit(edit, delete, reupload) their own details and the content they upload.
